ASS4 SPRING / SADP ASSIGNMENT - COMPLETE RUN + THUNDER CLIENT GUIDE
================================================================

ZIP CONTENTS
-------------
1. q1         - HR Application (Spring Core, console; NO REST API)
2. q2         - Task Management REST API (port 8081)
3. q3         - User Registration + Login REST API (port 8080)
4. q4         - Employee Flat File REST API (port 8082)
5. extra_q1   - ERP Product/Sales REST API (port 8083)
6. extra_q2   - Inventory REST API (port 8084)

LINUX PREREQUISITES
-------------------
java -version
mvn -version

If Maven is not installed (Ubuntu/Debian):
sudo apt update
sudo apt install openjdk-11-jdk maven -y

The projects contain Maven Wrapper. You can use ./mvnw instead of mvn.

GENERAL COMMANDS
----------------
cd /path/to/ass4/ass4
chmod +x q1/mvnw q2/mvnw q3/mvnw q4/mvnw extra_q1/mvnw extra_q2/mvnw

For each Spring Boot REST project:
./mvnw clean package
./mvnw spring-boot:run

OR after package:
java -jar target/*.jar

Q3 - USER AUTHENTICATION REST API
============================================================
Location: q3
Port: 8080
Base URL: http://localhost:8080/api/auth
Main class: com.auth.AuthApp

Run:
cd q3
./mvnw clean package
./mvnw spring-boot:run

Endpoints:
1. POST http://localhost:8080/api/auth/register
2. POST http://localhost:8080/api/auth/login

REGISTER JSON:
{
  "username": "vivek123",
  "email": "vivek@example.com",
  "password": "password123",
  "fullName": "Vivek Singh",
  "phone": "9876543210"
}

LOGIN JSON:
{
  "username": "vivek123",
  "password": "password123"
}

Validation:
- username: required, 3-20 characters
- email: valid email required
- password: required, minimum 6 characters
- fullName: required
- phone: exactly 10 digits if supplied

Thunder Client order:
POST /api/auth/register
POST /api/auth/login

Expected register response:
{
  "message": "Registration successful",
  "userId": 1,
  "username": "vivek123"
}

Expected login response:
{
  "message": "Login successful",
  "username": "vivek123",
  "fullName": "Vivek Singh"
}

Q4 - EMPLOYEE FLAT FILE REST API
============================================================
Location: q4
Port: 8082
Base URL: http://localhost:8082/api/employees
Main class: com.employee.EmpApp
Data file: employees.txt

Run:
cd q4
./mvnw clean package
./mvnw spring-boot:run

IMPORTANT:
When the application starts, EmpApp also asks for console input:
Eno:
Ename:
Designation:
DeptName:
Salary:
Enter example values:
101
Vivek Singh
Developer
IT
50000

This saves one employee into employees.txt. The REST API remains available on port 8082.

Endpoints:
1. POST http://localhost:8082/api/employees
2. GET  http://localhost:8082/api/employees
3. GET  http://localhost:8082/api/employees/dept/{deptName}

POST JSON:
{
  "eno": 101,
  "ename": "Vivek Singh",
  "designation": "Developer",
  "deptName": "IT",
  "salary": 50000
}

Another POST JSON:
{
  "eno": 102,
  "ename": "Priya Sharma",
  "designation": "HR Manager",
  "deptName": "HR",
  "salary": 60000
}

Thunder Client order:
POST /api/employees
GET /api/employees
GET /api/employees/dept/IT
GET /api/employees/dept/HR

============================================================
THUNDER CLIENT COMMON SETTINGS
============================================================
For POST/PUT:
Method: POST or PUT
URL: exact endpoint above
Headers:
Content-Type: application/json
Body -> JSON -> paste the JSON body

For GET:
Method: GET
URL: exact endpoint
No body required.

For DELETE:
Method: DELETE
URL: exact endpoint
No body required.
